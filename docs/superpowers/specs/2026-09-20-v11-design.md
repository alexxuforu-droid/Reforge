# Reforge v1.1 "Lightning + Trust" Design Spec

Date: 2026-09-20. Status: approved for implementation (perf headline + 5 bets, split behind green gates, 6-8 tracks).

## 1. Problem

v1.0.0 shipped (17 views, 278 Tauri commands, 23.5k Rust lines) but: 4-8 sequential IPC round-trips per view mount, full 200-entry undo log (336 KB) shipped to hot paths instead of 0.6 KB digest (507x waste), scan 0.77 GB/s sequential, dist JS ~958 KB with whip/fun/mock/makeover eagerly bundled, god-files (Makeover 1257, Settings 1209, ui ~1130, undo.rs 1167, security_center 1153), no PR CI, i18n ratchet at 934 hardcoded strings, palette keyboard dead, updater never carried a real release.

## 2. Goal (one sentence)

Cut user-felt latency 5-20x combined across boot, IPC bytes, scan throughput, bundle weight while splitting god-files behind green gates and shipping 5 shippable-alone product bets.

## 3. Non-goals / hard constraints

- Windows 10 & 11 only, per-user scope. WebView2 required.
- Unsigned permanently: keep "Unknown publisher" honesty copy in README + Settings About. No cert purchase.
- Local-first, no telemetry. No MSIX, no cloud backup, no boot/login skinning, no DLL injection, no irreversible delete, no shell-string concat from user input.
- Every mutation logs undo entry BEFORE change. Dry-run-first cleanup. Staging trash. Registry/Wi-Fi backups restorable from History.
- UI: monochrome + live OS accent (5s re-poll, fallback #0067C0), 4px grid, radius 4/8/12, Mica base, Segoe UI Variable, <=100ms motion + prefers-reduced-motion kill, flat skeleton pulse only.
- Typed `Result<T,AppError>` end-to-end; frontend branches on `kind`, never message substrings.

## 4. Architecture

Measure first (re-stamp `docs/perf-baseline.json`), split biggest-first with suite+E2E before/after and zero behavior change, then build bets on the faster base. Single composite `get_dashboard_summary` + parallel `useLoad`; `get_undo_digest` on hot paths; size->partial->full hash cascade + parallel walker; lazy whip/fun/makeover chunks; per-module `Revertible` trait in Rust; atomic JSON writes; single scheduler replacing 10+ polling threads.

## 5. Components

1. **Perf core**: `scripts/perf-*.mjs`, `src-tauri/src/lib.rs` (startup), `dashboard.rs` (new composite), `undo.rs` (digest), `duplicates.rs`/`files.rs` (parallel cascade), `vite.config.ts` (lazy splits).
2. **Frontend splits**: Makeover -> 6 lazy routes; Settings -> sub-nav + 8 lazy sections; ui.tsx -> Toast/Modal/Form/KindChip modules; types.ts -> per-domain; index.css dark-block dedupe; whip-sim.js typed/isolated.
3. **Backend hardening**: undo trait, spawn_blocking, atomic writes, error finish, version_band fix, PS parsing, updater handoff verify.
4. **CI/Quality**: `.github/workflows/ci.yml`, coverage widen, E2E retries+axe+Firefox smoke, pack fuzz.
5. **i18n+a11y**: ratchet 934->0 slices, plural fix, palette keyboard, focus/contrast sweep.
6. **UX/IA**: rename styles/makeover collision, collapsible sidebar, status bar, Settings sub-nav, Dashboard 2.0 risk trend, History filters, notifications center.
7. **Bets**: Look rotator, Maintenance autopilot, Pack diffing, Widget gallery, Risk v2 (each shippable alone).
8. **Release S-gates**: real release workflow, draft publish + site, live update-loop proof, remote refresh, clean-account smoke.

## 6. Data flow

Boot: `lib.rs setup` -> migrations -> deferred restore (1.5s) -> main window interactive -> parallel `get_dashboard_summary` + `get_undo_digest`. Scans: walker threads -> throttled `scan-progress` events (~20/s). Mutations: capture before-payload -> write -> log undo entry (cap 200) -> snapshot optionally. Updates: manifest check -> curl download -> sha256 verify -> stage -> NSIS swap.

## 7. Error handling

Rust `AppError { Io{path}, Registry{key}, Command(String), NotFound, Invalid }` serialized tagged. Frontend `errorCopy()` maps kind->copy. New code must construct `Io`/`Registry` at boundaries, never `to_string()` into `Command`. Unknown undo kind -> `Cannot revert kind`, mark nothing done.

## 8. Testing

`scripts/test-ci.sh` 12 gates + `cargo fmt/clippy/test` + `npm run test:e2e` must stay green before/after every split. Perf regression gate: boot over budget / round-trips up / GB/s down >10% / bundle up >5% -> fail. New bets each add vitest + Rust + 1 E2E journey.

## 9. Acceptance

- Headed cold boot <2s (stretch <1.5s), idle <200MB.
- Hot paths use digest (full-log bytes / digest bytes >= 400x on History/Dashboard).
- Scan >=2 GB/s on 120MB fixture (stretch 3+).
- dist JS down >=15% via lazy splits.
- No touched file >800 lines; undo arms covered; PR CI green; i18n ratchet falling; updater proven live with one real draft->install loop.
